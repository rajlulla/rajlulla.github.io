# Projects

## [Hackintosh EFI](https://github.com/rajlulla/hackintosh-efi)
A custom EFI configuration for an Intel i9-12900K based water-cooled Hackintosh build in a NANOQ S case, supporting MacOS Sequoia and Windows 11 dual-boot setup.

## [eul - Liquid Cooling Fork](https://github.com/rajlulla/eul)
An enhanced fork of the original eul system monitor that adds liquid cooling information support, displaying temperature and flow data from compatible devices like the Aquacomputer Quadro controller.

## [Ticketmaster API](https://github.com/rajlulla/TicketmasterAPI)
A Dockerized FastAPI application providing three API endpoints to interact with Ticketmaster, leveraging Puppeteer to extract cookies and intercept specific URLs for ticket price queries.

## [Transmission iOS Client](https://github.com/rajlulla/Transmission)
An iOS client application that interacts with a Transmission torrent client instance using its API for remote management capabilities.

## [Poker Balance Calculator](https://github.com/rajlulla/PokerCalculator)
A simple iOS app to calculate and settle balances for poker games, available on the [App Store](https://apps.apple.com/us/app/poker-balance-calculator/id6654929922).

## [Apple In Stock Bot](https://github.com/rajlulla/AppleInStockBot)
A notification bot that checks Apple product stock availability and sends alerts via Telegram when desired products become available for purchase.

## [Ticket Monitor Frontend](https://github.com/rajlulla/tickets-frontend)
A basic web frontend to monitor bots that track ticket prices from services like Ticketmaster and StubHub for easier viewing and management.
